# SADT-моделирование клиники «Лапа»

## IDEF0
- контекст A0: «Оказать ветеринарную помощь»;
- декомпозиция A1–A4: учёт владельца и животного, запись на приём, осмотр, диагноз и лечение;
- не менее трёх уровней декомпозиции.

## IDEF3
Сценарий приёма: заявка → подтверждение слота → осмотр → протокол → назначения.

## DFD
Потоки данных между владельцем, регистратором, врачом, администратором и хранилищами «Пациенты», «Записи», «ЭМК», «Пользователи».
