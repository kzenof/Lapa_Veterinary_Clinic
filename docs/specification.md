# Спецификация ПО клиники «Лапа»

## Функциональные требования
- регистрация и авторизация клиента;
- запись на приём (дата, время, специалист);
- АРМ регистратора: новая запись, пациенты, расписание;
- АРМ врача: очередь, протокол осмотра, ЭМК;
- CORE_ADMIN: пользователи, роли, блокировка, бэкап.

## Нефункциональные требования
- разграничение доступа по ролям;
- хранение персональных данных в соответствии с 152-ФЗ;
- клиент–сервер–БД;
- резервное копирование базы.
