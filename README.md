# LAPA — информационная система ветеринарной клиники

Репозиторий учебной практики **УП.02** (вариант 29): автоматизация работы ветеринарной клиники «Лапа».

## Назначение

Проект содержит модели бизнес-процессов (SADT/UML), спецификацию и ТЗ, HTML-прототипы интерфейсов и исходный код GUI на C++/Qt.

## Ветки по кейс-задачам

| Ветка | Содержание |
|---|---|
| `main` | описание проекта (этот README) |
| `case_task1` | моделирование: IDEF0/IDEF3/DFD, UML |
| `case_task2` | архитектура, спецификация, ТЗ, HTML-прототипы |
| `case_task3` | графический интерфейс на C++/Qt |
| `case_task4` | организация хранения проекта в GitHub |

В каждой рабочей ветке каталоги: `docs`, `src`, `tests`, `source` (в задании указано `sourse`).

## Роли

- клиент (владелец животного);
- регистратор;
- ветеринарный врач;
- системный администратор (CORE_ADMIN).
